## Why

Проект VPN Telegram-бота начинается с нуля. Необходимо зафиксировать технический стек, архитектурные принципы и стандарты кода до начала реализации, чтобы обеспечить единообразие, масштабируемость и качество кодовой базы. Бот будет управлять VPN-подписками через 3x-ui панель.

## What Changes

- Определяется технический стек: PHP 8.5, Symfony 8.0, Nutgram, SQLite + Doctrine, Docker
- Фиксируется модульная архитектура: Hexagonal + CQRS внутри каждого модуля
- Определяется структура проекта: `src/{Module}/Domain|Application|Infrastructure`
- Определяется MVP (v1): подключение через заявку, инструкции, статус, рассылка, админ-одобрение
- Определяется v2 roadmap: оплата, реферальная система

## Capabilities

### New Capabilities
- `tech-stack`: Технический стек проекта — языки, фреймворки, библиотеки, инфраструктура
- `architecture`: Архитектурные принципы — модульная структура, Hexagonal, CQRS, слои Domain/Application/Infrastructure
- `coding-standards`: Стандарты кода — именование, форматирование, паттерны, тестирование
- `mvp-scope`: Объём MVP (v1) и roadmap (v2) — фичи, границы, приоритеты

## Impact
