## MODIFIED Requirements

### Requirement: Ответ на сообщение
Бот SHALL обрабатывать команду /start с приветствием и inline-кнопками вместо ответа "Привет!" на любое сообщение. Неизвестные сообщения SHALL игнорироваться.

#### Scenario: Пользователь отправляет /start
- **WHEN** пользователь отправляет /start
- **THEN** бот отправляет приветственное сообщение с inline-кнопками: Подключиться, Текущий статус, Поддержка

#### Scenario: Пользователь отправляет неизвестное сообщение
- **WHEN** пользователь отправляет произвольный текст
- **THEN** бот не отвечает (или предлагает использовать /start)
