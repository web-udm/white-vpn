## ADDED Requirements

### Requirement: Просмотр статуса подписки
Бот SHALL показывать текущий статус подписки с данными из 3x-ui API.

#### Scenario: Активная подписка
- **WHEN** пользователь с активным клиентом в 3x-ui нажимает "Текущий статус"
- **THEN** бот показывает: статус "АКТИВНА", оставшиеся дни, дата окончания, subscription URL (ссылка на подключение)

#### Scenario: Нет подключения
- **WHEN** пользователь без клиента в 3x-ui нажимает "Текущий статус"
- **THEN** бот показывает статус "НЕ АКТИВНА" и предлагает подключиться

#### Scenario: Подписка истекла
- **WHEN** пользователь с истёкшим клиентом нажимает "Текущий статус"
- **THEN** бот показывает статус "ИСТЕКЛА", дату окончания

#### Scenario: 3x-ui API недоступен
- **WHEN** пользователь нажимает "Текущий статус", но 3x-ui API не отвечает
- **THEN** бот сообщает "Сервис временно недоступен, попробуйте позже"

### Requirement: Поддержка
Бот SHALL отправлять ссылку на контакт администратора при нажатии "Поддержка".

#### Scenario: Запрос поддержки
- **WHEN** пользователь нажимает "Поддержка"
- **THEN** бот отправляет сообщение со ссылкой на @moildar
