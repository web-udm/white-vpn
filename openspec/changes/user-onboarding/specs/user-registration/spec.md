## ADDED Requirements

### Requirement: User entity
Система SHALL хранить пользователей в SQLite с полями: telegram_id (уникальный, неизменяемый), xui_email (формат `tg_{telegram_id}`), created_at.

#### Scenario: Новый пользователь
- **WHEN** пользователь впервые взаимодействует с ботом
- **THEN** создаётся запись User с telegram_id и xui_email = `tg_{telegram_id}`

#### Scenario: Повторный пользователь
- **WHEN** пользователь уже существует в БД
- **THEN** новая запись не создаётся, используется существующая

### Requirement: Команда /start
Бот SHALL отображать приветственное сообщение при команде /start с inline-кнопками: Подключиться, Текущий статус, Поддержка.

#### Scenario: Первый запуск
- **WHEN** новый пользователь отправляет /start
- **THEN** бот сохраняет пользователя в БД и отправляет приветствие с inline-кнопками

#### Scenario: Повторный запуск
- **WHEN** существующий пользователь отправляет /start
- **THEN** бот отправляет приветствие с inline-кнопками без дублирования записи
